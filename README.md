# 🚀 Dataverse Dev Journey: Zero to Mastery

Welcome to the official **Dataverse Dev Journey** repository! This space is an open knowledge hub dedicated to exploring, simplifying, and deepening development and architecture in the **Microsoft Dataverse**, **Power Platform** ecosystem and related technologies (.NET, C#, JavaScript, AI, and ALM).

The goal of this project is to guide developers from fundamental concepts to advanced architecture scenarios, combining theory, productivity tips, and practical implementation.

---

## 📁 Repository Structure

The repository is organized modularly to facilitate consultation and learning:

```text
dataverse-dev-journey/
├── articles/
│   ├── back-to-basics/       # Fundamentals and concepts articles (B2B)
│   ├── dynamics-dev-drops/   # Quick tips and code snippets (DDD)
│   └── dynamics-dev-pill/    # Deep articles and architecture guides (DDP)
├── estudos/                  # Raw notes and weekly study roadmaps
└── assets/                   # Banners, diagrams, and images for posts
```
